一、物理模拟算法原理与实现

物理模拟是游戏引擎中赋予虚拟世界"真实感"的核心技术，通过数学模型模拟现实世界的物理规律， 让游戏对象的运动符合玩家的直觉认知。本章将详细解析物理模拟的核心算法与实现细节。

1.1 物理模拟的基本框架与流程

物理模拟通过数学模型模拟现实世界的物理规律（如重力、碰撞、摩擦力），让游戏对象的运动符合玩家的直觉认知。 在本代码中，物理模拟主要涉及物块运动和碰撞处理两大核心功能。

物理模拟的基本流程通常包括以下几个关键步骤：

1

积分(Integrate)

根据物体的当前状态（位置、速度、加速度等）和作用于物体的力，计算下一时刻的位置和速度。

2

碰撞检测

检测物体之间是否发生碰撞，包括粗略碰撞检测(Broad Phase)和精确碰撞检测(Narrow Phase)。

3

碰撞约束

处理碰撞后的物理响应，包括反弹力、摩擦力的计算以及物体运动状态的更新。

在代码中，这一流程通常通过游戏循环中的固定时间步长更新实现，确保物理模拟的稳定性和一致性。

1.2 物块运动的数学模型与积分方法

物块运动的模拟基于牛顿第二定律(F = ma)，通过积分方法计算物体在力作用下的位置和速度变化。 在本代码中，采用了半隐式欧拉积分法，这是游戏物理中常用的积分方法，能够在保证计算效率的同时提供较好的数值稳定性。

半隐式欧拉积分法的数学表达式

\( v_{n+1} = v_n + a_n \cdot dt \)

\( x_{n+1} = x_n + v_{n+1} \cdot dt \)

其中，\( v \) 表示速度，\( a \) 表示加速度，\( x \) 表示位置，\( dt \) 表示时间步长。 与显式欧拉法不同，半隐式欧拉法先更新速度再更新位置，能够更好地保持能量守恒，避免数值不稳定问题。

代码实现

void integrate(RigidBody& body, float deltaTime) {
    // 计算加速度
    body.acceleration = body.force / body.mass;
    
    // 半隐式欧拉积分：先更新速度，再更新位置
    body.velocity += body.acceleration * deltaTime;
    body.position += body.velocity * deltaTime;
    
    // 类似地处理旋转运动（如果有的话）
}

这种积分方法在保持计算简单的同时，能够有效避免显式欧拉法可能导致的数值发散问题，特别适合实时物理模拟环境。

1.3 碰撞检测算法与实现细节

碰撞检测是物理模拟中的关键环节，决定了物体之间是否发生碰撞以及碰撞的具体位置和方向。 在代码中，碰撞检测通常分为两个阶段：粗略碰撞检测(Broad Phase)和精确碰撞检测(Narrow Phase)。

粗略碰撞检测

通常使用包围盒（如AABB包围盒）进行快速过滤，排除明显不相交的物体对，减少精确碰撞检测的计算量。

    // 可能发生碰撞，进行精确碰撞检测
    if (polygonCollision(polygonA, polygonB)) {
        // 处理碰撞
    }
}

精确碰撞检测

使用更精确的几何算法判断两个物体是否相交，并计算碰撞点、碰撞法线和穿透深度等信息。 常见的精确碰撞检测算法包括：

  • 分离轴定理(SAT)：用于检测两个凸多边形是否相交，通过检查所有可能的分离轴来判断是否存在分离的方向。
  • GJK算法：用于计算两个凸形状之间的最短距离，是一种高效的碰撞检测算法。
  • 点到线段/平面/方盒的距离计算：用于检测点与各种几何形状的碰撞。
bool polygonCollision(Polygon& a, Polygon& b) {

        Vector2 axis = a.edges[i].normal();

        }
    }
    return true;
}

1.4 碰撞响应与约束求解

碰撞响应处理是物理模拟中最复杂的部分，它决定了物体在碰撞后的运动状态变化。 碰撞响应的目标是根据碰撞信息计算合理的反弹速度和摩擦力，确保物体运动符合物理规律。

碰撞响应的数学表达式

\( J = -(1 + e) \cdot v_{rel} \cdot n / (1/m_1 + 1/m_2) \)

\( v_{1_{new}} = v_1 + J/m_1 \cdot n \)

\( v_{2_{new}} = v_2 - J/m_2 \cdot n \)

其中，\( J \) 是碰撞冲量，\( e \) 是弹性系数，\( v_{rel} \) 是相对速度， \( n \) 是碰撞法线，\( m_1 \) 和 \( m_2 \) 是两物体的质量。

代码实现

void resolveCollision(RigidBody& a, RigidBody& b, Vector2 contact, Vector2 normal) {
    // 计算相对速度
    Vector2 v_rel = b.velocity - a.velocity;
    
    // 计算弹性系数
    float e = min(a.restitution, b.restitution);
    
    // 计算冲量大小
    float j = -(1 + e) * dot(v_rel, normal) / (1/a.mass + 1/b.mass);
    
    // 应用冲量
    a.velocity += j / a.mass * normal;
    b.velocity -= j / b.mass * normal;
    
    // 处理摩擦力（简化版）
    Vector2 tangent = v_rel - dot(v_rel, normal) * normal;
    if (length(tangent) > 1e-6) {
        tangent = normalize(tangent);
        float friction = min(-dot(v_rel, tangent), 0.5);
        a.velocity += friction * tangent;
        b.velocity -= friction * tangent;
    }
    
    // 解决穿透问题
    float penetration = 0.1; // 假设穿透深度
    a.position -= penetration * normal * a.mass / (a.mass + b.mass);
    b.position += penetration * normal * b.mass / (a.mass + b.mass);
}

在代码中，物块与边界的碰撞检测和响应通常采用以下方法：

  1. 检测物块是否超出边界范围：检查物块的位置是否超出游戏世界的边界。
  2. 修正物块位置：将物块的位置调整到边界内，避免穿透。
  3. 计算反弹速度：根据边界的法线和物块的速度计算反弹后的速度。

例如，处理物块与左右边界碰撞的代码可能如下：

1.6 物块间的弹性碰撞处理

物块间的弹性碰撞处理比物块与边界的碰撞处理更复杂，需要考虑两个物体的质量、速度和弹性系数等因素。

在弹性碰撞中，动量和动能（在完全弹性碰撞中）守恒。在代码中，物块间的弹性碰撞处理通常包括以下步骤：

  1. 计算碰撞法线：确定碰撞点处的法线方向。
  2. 计算相对速度：确定两物块在碰撞点处的相对速度。
  3. 计算碰撞冲量：根据弹性系数和相对速度计算所需的冲量。
  4. 更新物块速度：应用冲量，更新物块的速度。
  5. 修正物块位置：调整物块的位置以消除穿透。

例如，处理两球碰撞的代码可能如下：

void checkBallCollision(Ball& b1, Ball& b2) {
    // 计算两球中心距离
    float dx = b1.x - b2.x;
    float dy = b1.y - b2.y;
    float dist = sqrt(dx*dx + dy*dy);
    
    if (dist < b1.radius + b2.radius) {
        // 计算碰撞法线
        float nx = dx / dist;
        float ny = dy / dist;
        
        // 计算相对速度
        float v1n = b1.vx * nx + b1.vy * ny;
        float v2n = b2.vx * nx + b2.vy * ny;
        
        // 计算弹性系数
        float e = 0.8; // 假设弹性系数为0.8
        
        // 计算冲量
        float j = -(1 + e) * (v1n - v2n) / (1/b1.mass + 1/b2.mass);
        
        // 更新速度
        b1.vx += j * nx / b1.mass;
        b1.vy += j * ny / b1.mass;
        b2.vx -= j * nx / b2.mass;
        b2.vy -= j * ny / b2.mass;
        
        // 修正位置以消除穿透
        float overlap = (b1.radius + b2.radius - dist) / 2;
        b1.x += overlap * nx;
        b1.y += overlap * ny;
        b2.x -= overlap * nx;
        b2.y -= overlap * ny;
    }
}

1.7 摩擦力的模拟与实现

摩擦力是物理模拟中另一个重要的力，它影响物体在表面上的滑动和滚动。在代码中，摩擦力的模拟通常基于库仑摩擦定律，分为静摩擦力和动摩擦力。

在物理模拟中，摩擦力的计算通常包括以下步骤：

  1. 计算法向力：确定接触面的法向力。
  2. 计算最大静摩擦力：最大静摩擦力等于法向力乘以静摩擦系数。
  3. 计算动摩擦力：动摩擦力等于法向力乘以动摩擦系数，方向与相对运动方向相反。
  4. 应用摩擦力：根据物体的运动状态（静止或滑动）应用相应的摩擦力。

在代码中，摩擦力的实现可能如下：

void applyFriction(RigidBody& body, float friction_coeff) {
    // 计算法向力（假设为重力）
    float normal_force = body.mass * GRAVITY;
    
    // 计算最大静摩擦力
    float max_static_friction = friction_coeff * normal_force;
    
    // 计算动摩擦力
    float dynamic_friction = friction_coeff * normal_force;
    
    // 如果物体静止，应用静摩擦力
    if (abs(body.velocity.x) < 1e-6) {
        body.force.x = clamp(body.force.x, -max_static_friction, max_static_friction);
    } else {
        // 应用动摩擦力，方向与运动方向相反
        body.force.x -= sign(body.velocity.x) * dynamic_friction;
    }
}

二、连续碰撞检测(CCD)原理与实现

2.1 连续碰撞检测(CCD)的基本原理

连续碰撞检测(Continuous Collision Detection, CCD)是物理模拟中的一项高级技术，用于解决高速运动物体在离散时间步长下可能出现的"穿墙"问题。传统的离散碰撞检测(Discrete Collision Detection, DCD)只在每个时间步的开始和结束时检测碰撞，对于高速运动的物体，可能在一个时间步内从障碍物的一侧移动到另一侧而不被检测到，导致"穿墙"现象。

CCD的基本思想是将物体在一个时间步内的运动视为连续的轨迹，检测该轨迹是否与障碍物相交，从而确定是否发生了碰撞。这种方法能够更准确地检测高速运动物体的碰撞，避免"穿墙"问题。

CCD的数学原理是：在时间区间[0, dt]内，物体从位置P0移动到位置P1，其运动轨迹可以表示为参数方程：

P(t) = P0 + t*(P1 - P0), t ∈ [0, 1]

CCD通过求解该参数方程与障碍物表面的交点，确定碰撞是否发生以及碰撞发生的时间。

2.2 连续碰撞检测的两种主要方法

在物理模拟中，常用的连续碰撞检测方法有两种：基于扫掠的CCD(Sweep-based CCD)和推测性CCD(Speculative CCD)。

基于扫掠的CCD

采用撞击时间(Time of Impact, TOI)算法，通过扫掠对象的前向轨迹来计算对象的潜在碰撞（采用对象的当前速度）。如果沿对象移动方向有接触，该算法会计算撞击时间并移动对象直至达到该时间。

该算法可从该时间开始执行子步骤，即计算TOI之后的速度，然后重新扫掠，代价是需要经历更多的CPU周期。

推测性CCD

工作原理是基于对象的线性运动和角运动增大一个对象的粗筛阶段轴对齐最小包围盒(AABB)。该算法是一种推测性的算法，因为会选取下一物理步骤中的所有潜在触点。

然后将所有触点送入解算器，因此可确保满足所有的触点约束，使对象不会穿过任何碰撞。

这两种方法各有优缺点：

方法 优点 缺点
基于扫掠的CCD 检测准确，无"穿墙"现象 计算量大，未考虑角速度
推测性CCD 计算效率高，实现简单 可能产生幽灵碰撞，存在穿隧现象

在代码中，通常根据具体需求选择合适的CCD方法。对于高速运动的物体，如子弹、炮弹等，通常使用基于扫掠的CCD；对于一般的刚体运动，推测性CCD可能更适合。

2.4 时间步长内多次碰撞的迭代处理

在实际物理模拟中，一个时间步长内可能发生多次碰撞，特别是当物体与多个障碍物或多个物体相互作用时。为了处理这种情况，需要在检测到碰撞后，将时间步长分割为多个子步长，依次处理每个碰撞。

在代码中，处理一个时间步长内多次碰撞的迭代处理通常包括以下步骤：

  1. 初始化当前时间和剩余时间：设置当前时间为0，剩余时间为整个时间步长dt。
  2. 循环处理碰撞：
    1. 检测当前时间到当前时间+剩余时间内的碰撞。
    2. 如果检测到碰撞，记录碰撞时间和碰撞信息。
    3. 处理碰撞，更新物体的运动状态。
    4. 更新剩余时间，从剩余时间中减去已处理的时间。
    5. 更新当前时间，将当前时间加上已处理的时间。
  3. 当剩余时间为0或没有更多碰撞时，结束循环。

在代码中，这种迭代处理的实现可能如下：

void processCollisions(PhysicsWorld& world, float dt) {
    float current_time = 0;
    float remaining_time = dt;
    
    while (remaining_time > 1e-6) {
        // 保存当前状态，以便在碰撞时回滚
        std::vector<RigidBody> old_states = world.getBodies();
        
        // 检测下一次碰撞的时间和信息
        float collision_time;
        CollisionInfo collision_info;
        bool has_collision = world.detectCollision(current_time, remaining_time, collision_time, collision_info);
        
        if (has_collision) {
            // 处理碰撞
            world.resolveCollision(collision_info);
            
            // 更新当前时间和剩余时间
            current_time += collision_time;
            remaining_time -= collision_time;
            
            // 重置物体状态，以便在下一个子步长中使用新的速度
            world.resetBodies(old_states);
        } else {
            // 没有碰撞，直接推进剩余时间
            current_time += remaining_time;
            remaining_time = 0;
        }
    }
}

GJK(Gilbert-Johnson-Keerthi)算法是一种高效的碰撞检测算法，最初用于检测两个凸形状是否相交，也可以扩展用于连续碰撞检测。

GJK算法的基本思想是通过构造一个支持函数来逐步逼近两个形状的最短距离，并判断它们是否相交。该算法的步骤包括初始化、构建简单形状、迭代和终止条件判断。

2.7 时间参数化在连续碰撞检测中的应用

时间参数化是一种有效的技术，用于在物体运动的过程中进行碰撞检测。通过将物体的运动表示为一个时间参数化的函数，可以在两帧之间的时间范围内（通常是从0到1）进行插值，从而找到物体与其他物体的交点，并确定碰撞发生的确切时间。

在代码中，时间参数化通常用于将物体在时间t的位置表示为：

P(t) = P0 + (P1 - P0)·t

其中，P0是物体在时间0的位置，P1是物体在时间1的位置，t ∈ [0, 1]。

五、数学原理与物理公式

5.1 牛顿运动定律与积分方法

牛顿运动定律是物理模拟的基础，特别是牛顿第二定律(F = ma)，它描述了力、质量和加速度之间的关系。在物理模拟中，牛顿第二定律用于计算物体在力作用下的加速度，进而通过积分方法计算物体的速度和位置变化。

牛顿第二定律代码应用：

// 计算加速度
Vector2 acceleration = force / mass;
// 积分计算速度和位置
velocity += acceleration * dt;
position += velocity * dt;

常用积分方法：

1. 显式欧拉积分
v_{n+1} = v_n + a_n * dt
x_{n+1} = x_n + v_n * dt

简单但可能不稳定，容易导致能量发散。

2. 半隐式欧拉积分
v_{n+1} = v_n + a_n * dt
x_{n+1} = x_n + v_{n+1} * dt

更稳定，能够保持能量守恒，是游戏物理中最常用的积分方法。

3. Verlet积分
x_{n+1} = 2x_n - x_{n-1} + a_n * dt^2

不需要显式计算速度，适用于位置约束较多的情况。

积分方法代码实现：

// 显式欧拉积分
void eulerIntegrate(Vector2& position, Vector2& velocity, Vector2 acceleration, float dt) {
    velocity += acceleration * dt;
    position += velocity * dt;
}

// 半隐式欧拉积分
void semiImplicitEulerIntegrate(Vector2& position, Vector2& velocity, Vector2 acceleration, float dt) {
    Vector2 new_velocity = velocity + acceleration * dt;
    position += new_velocity * dt;
    velocity = new_velocity;
}

// Verlet积分
void verletIntegrate(Vector2& position, Vector2& old_position, Vector2 acceleration, float dt) {
    Vector2 new_position = 2 * position - old_position + acceleration * dt * dt;
    old_position = position;
    position = new_position;
}

5.2 动量守恒与弹性碰撞公式

动量守恒定律是物理学中的基本定律，它指出在一个封闭系统中，总动量保持不变。在物理模拟中，动量守恒定律用于处理物体之间的碰撞问题。

弹性碰撞核心公式：

动量守恒：

m1*v1 + m2*v2 = m1*v1' + m2*v2'

动能守恒（完全弹性碰撞）：

0.5*m1*v1² + 0.5*m2*v2² = 0.5*m1*v1'² + 0.5*m2*v2'²

碰撞后速度解：

v1' = (m1 - m2)/(m1 + m2) * v1 + 2*m2/(m1 + m2) * v2

v2' = 2*m1/(m1 + m2) * v1 + (m2 - m1)/(m1 + m2) * v2

弹性碰撞代码实现：

void elasticCollision(float m1, float m2, float& v1, float& v2) {
    float v1_new = ((m1 - m2) * v1 + 2 * m2 * v2) / (m1 + m2);
    float v2_new = ((m2 - m1) * v2 + 2 * m1 * v1) / (m1 + m2);
    v1 = v1_new;
    v2 = v2_new;
}

非弹性碰撞公式：

引入恢复系数e（0 ≤ e ≤ 1），表示碰撞后相对速度与碰撞前相对速度的比值：

e = -(v1' - v2') / (v1 - v2)

非弹性碰撞后速度公式：

v1' = (m1 - e*m2)/(m1 + m2) * v1 + (1 + e)*m2/(m1 + m2) * v2

v2' = (1 + e)*m1/(m1 + m2) * v1 + (m2 - e*m1)/(m1 + m2) * v2

非弹性碰撞代码实现：

void inelasticCollision(float m1, float m2, float& v1, float& v2, float e) {
    float v1_new = ((m1 - e*m2) * v1 + (1 + e)*m2 * v2) / (m1 + m2);
    float v2_new = ((1 + e)*m1 * v1 + (m2 - e*m1) * v2) / (m1 + m2);
    v1 = v1_new;
    v2 = v2_new;
}

5.3 能量守恒与功的计算

能量守恒定律是物理学中的另一个基本定律，它指出在一个封闭系统中，总能量保持不变。在物理模拟中，能量守恒定律用于验证模拟的正确性和优化积分方法。

主要能量形式及公式：

1. 动能

物体由于运动而具有的能量：

KE = 0.5 * m * v²

2. 重力势能

物体由于位置而具有的能量：

PE = m * g * h

3. 弹性势能

物体由于形变而具有的能量：

PE_spring = 0.5 * k * x²

总能量为各类能量的总和：

E_total = KE + PE + PE_spring + ...

能量计算代码实现：

float calculateKineticEnergy(float mass, float velocity) {
    return 0.5 * mass * velocity * velocity;
}

float calculateGravitationalPotentialEnergy(float mass, float height, float gravity) {
    return mass * gravity * height;
}

float calculateSpringPotentialEnergy(float spring_constant, float displacement) {
    return 0.5 * spring_constant * displacement * displacement;
}

5.4 质量比与碰撞响应的关系

质量比是影响碰撞响应的重要因素，它决定了碰撞后物体速度的变化。在物理模拟中，质量比(m1/m2)直接影响碰撞后物体的速度分配。

质量比对碰撞速度的影响：

基于碰撞后速度公式：

v1' = (m1 - m2)/(m1 + m2) * v1 + 2*m2/(m1 + m2) * v2

v2' = 2*m1/(m1 + m2) * v1 + (m2 - m1)/(m1 + m2) * v2

  • 当m1 = m2时，碰撞后两物体交换速度。
  • 当m1 >> m2时，第一个物体几乎不受影响，第二个物体以两倍速度弹开。
  • 当m1 << m2时，第一个物体以几乎相反的速度弹回，第二个物体几乎不动。

质量比应用代码实现：

// 计算质量比
float mass_ratio = m1 / m2;
// 根据质量比调整碰撞响应
if (mass_ratio > 100) { // 当m1远大于m2时
    // 处理m1几乎不动的情况
    v2 = 2*v1 - v2;
} else if (mass_ratio < 0.01) { // 当m1远小于m2时
    // 处理m2几乎不动的情况
    v1 = -v1;
} else {
    // 正常处理碰撞
    elasticCollision(m1, m2, v1, v2);
}

在某些物理问题中，需要计算物体在特定条件下可能发生的碰撞次数。这种理论碰撞次数的计算通常基于数学分析，而非数值模拟。

示例场景：小球在两个平行墙壁之间运动，弹性系数为e，初始速度为v，两墙距离为d。由于e < 1，小球动能逐渐减少，需设置速度阈值判断停止。

int calculateCollisionCount(float initial_velocity, float distance, float restitution, float threshold) {

    float velocity = initial_velocity;

        // 计算碰撞后的速度
        velocity *= -restitution;
        count++;
    }
    
    return count;
}

6.1 自适应时间步长计算

自适应时间步长是物理模拟中的一项重要优化技术，它根据模拟的复杂程度动态调整时间步长的大小，提高模拟效率和稳定性。

传统固定时间步长可能导致简单场景资源浪费或复杂场景不稳定，自适应时间步长通过误差估计动态调整步长，平衡精度与效率。

自适应时间步长基本原理：

  1. 误差估计：每个时间步结束后，估计模拟结果的误差。
  2. 调整时间步长：误差大时减小步长，误差小时增大步长。
  3. 范围限制：设置步长最小值和最大值，避免极端情况。

自适应时间步长代码实现：

void adaptiveTimeStepSimulation() {
    float current_time = 0;
    float target_time = 10.0; // 总模拟时间
    float dt = 0.1; // 初始时间步长
    float min_dt = 0.001;
    float max_dt = 0.5;
    float error_threshold = 0.1;
    
    while (current_time < target_time) {
        // 保存当前状态
        auto old_state = getCurrentState();
        
        // 使用当前时间步长进行模拟
        simulateStep(dt);
        
        // 估计误差
        float error = estimateError(old_state);
        
        // 调整时间步长
        if (error > error_threshold) {
            dt *= 0.5; // 误差大，减小步长
        } else {
            dt *= 1.1; // 误差小，增大步长
        }
        
        // 限制时间步长范围
        dt = clamp(dt, min_dt, max_dt);
        
        // 更新当前时间
        current_time += dt;
    }
}

6.2 空间分区与碰撞检测优化

空间分区是物理模拟中用于优化碰撞检测的重要技术，它将游戏世界划分为多个区域，只检查同一区域或相邻区域内的物体之间的碰撞，减少不必要的碰撞检测操作。

常见空间分区方法：

  • 均匀网格：将世界划分为等大网格单元，检测当前及相邻单元物体。
  • 四叉树/八叉树：递归划分区域（二维四叉、三维八叉），直到区域物体数量足够少。
  • 层次包围盒：创建AABB树、OBB树等层次结构，快速排除不相交物体。

均匀网格分区代码实现：

// 均匀网格分区示例
class GridPartition {
public:
    GridPartition(int width, int height, int cell_size) :
        cell_size(cell_size),
        grid_width((width + cell_size - 1) / cell_size),
        grid_height((height + cell_size - 1) / cell_size) {
        grid.resize(grid_width * grid_height);
    }
    
    void addObject(PhysicsObject* obj) {
        int x = obj->getPosition().x / cell_size;
        int y = obj->getPosition().y / cell_size;
        if (x >= 0 && x < grid_width && y >= 0 && y < grid_height) {
            grid[x + y * grid_width].push_back(obj);
        }
    }
    
    void clear() {
        for (auto& cell : grid) {
            cell.clear();
        }
    }
    
    std::vector getPotentialCollisions(PhysicsObject* obj) {
        std::vector result;
        int x = obj->getPosition().x / cell_size;
        int y = obj->getPosition().y / cell_size;
        
        // 检查当前单元和相邻单元
        for (int dx = -1; dx <= 1; dx++) {
            for (int dy = -1; dy <= 1; dy++) {
                int nx = x + dx;
                int ny = y + dy;
                if (nx >= 0 && nx < grid_width && ny >= 0 && ny < grid_height) {
                    for (auto& other : grid[nx + ny * grid_width]) {
                        if (other != obj) {
                            result.push_back(other);
                        }
                    }
                }
            }
        }
        
        return result;
    }
    
private:
    int cell_size;
    int grid_width;
    int grid_height;
    std::vector> grid;
}

6.3 避免穿透与位置修正

穿透是物理模拟中常见的问题，当物体在一个时间步长内移动过快，导致从障碍物的一侧移动到另一侧而未被检测到，从而出现物体部分或全部位于障碍物内部的情况。为了解决穿透问题，需要进行位置修正。

避免穿透的方法：

  • 连续碰撞检测(CCD)：检测物体整个运动轨迹与障碍物的相交性。
  • 减小时间步长：降低穿透可能性，但增加计算量。
  • 碰撞后位置修正：检测到碰撞后，调整物体位置消除穿透。

碰撞后位置修正代码实现：

void resolvePenetration(RigidBody& a, RigidBody& b, Vector2 normal, float penetration) {
    // 计算修正量
    Vector2 correction = normal * penetration * 0.5;
    
    // 调整两物体的位置
    a.position -= correction * a.mass / (a.mass + b.mass);
    b.position += correction * b.mass / (a.mass + b.mass);
}

6.4 碰撞缓存与重复碰撞处理

碰撞缓存是一种优化技术，用于避免在连续的时间步中重复检测和处理相同的碰撞，提高模拟效率。

物体间碰撞可能在多个时间步持续存在（如物体静止在表面），重复处理会浪费资源。碰撞缓存通过记录近期碰撞，跳过已处理的碰撞对。

碰撞缓存实现步骤：

  1. 缓存碰撞对：检测到碰撞后，存储碰撞对（物体指针/索引）。
  2. 跳过已缓存碰撞：后续检测中，若碰撞对已在缓存则跳过。
  3. 定期清空缓存：确保新碰撞能被检测（如每个时间步结束）。

碰撞缓存代码实现：

class CollisionCache {
public:
    void addCollision(PhysicsObject* a, PhysicsObject* b) {
        // 使用有序对避免重复存储（如a < b）
        if (a > b) std::swap(a, b);
        cache.insert({a, b});
    }
    
    bool hasCollision(PhysicsObject* a, PhysicsObject* b) {
        if (a > b) std::swap(a, b);
        return cache.find({a, b}) != cache.end();
    }
    
    void clear() {
        cache.clear();
    }
    
private:
    std::set> cache;
};

void processCollisions(PhysicsWorld& world, CollisionCache& cache) {
    // 检测所有可能的碰撞对
    for (auto& a : world.getObjects()) {
        for (auto& b : world.getObjects()) {
            if (a != b && !cache.hasCollision(a, b) && aabbIntersect(a, b)) {
                if (polygonCollision(a, b)) {
                    resolveCollision(a, b);
                    cache.addCollision(a, b);
                }
            }
        }
    }
    
    // 处理静止接触
    handleRestingContacts(world, cache);
    
    // 清空缓存，为下一帧做准备
    cache.clear();
}
